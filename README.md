# ZenFlow — Sensory Relaxation PWA

**ZenFlow** is an interactive **ASMR & sensory-relaxation web app** — touch, feel, hear. Built **PWA-first** for a native-like mobile experience.

## Features

- Interactive audio-haptic relaxation experiences
- PWA: installable, offline-capable, mobile-first
- Smooth, tactile UI

## Tech stack

TypeScript · React · PWA · Tailwind CSS

## Run locally

```bash
git clone https://github.com/Wcoach24/zenflow.git
cd zenflow
npm install
npm run dev
```
